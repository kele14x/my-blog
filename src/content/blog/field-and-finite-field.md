在[上一篇 FEC 入门文章](/blog/fec-introduction/)中，我们用异或方程构造了汉明码：计算几个校验位，求出伴随式，就能定位一个比特的错误。但如果你继续翻编码/纠错相关的书时，域、多项式、根这些概念就开始频繁出现。纠正几个错误，怎么突然需要这么多代数知识了？

其实我们已经应用过域相关的概念了。“异或”和“与”运算，正是 $GF(2)$ 中的加法和乘法——这是一套用于单比特符号的算术。在更复杂的编码中，我们希望把单比特的算术扩展到多比特，比如字节。于是，一个看似简单的问题就变得很重要：**字节之间相乘，或者相除，到底应该怎么算？**

我们希望运算结果仍然落在一个字节（8-bit，256 个可能的取值）之中。最简单的想法是直接做普通整数运算，再只保留低八位。这看起来很方便，但是：

$$
2 \times 128 \equiv 0 \pmod{256}
$$

两个非零值相乘，结果却变成了零。“乘以 2”无法被唯一地逆转：0 和 128 乘以 2 都会得到相同的结果。**光是让结果装得进一个字节还不够；我们还希望，除以任意非零元素都能行得通。**

有限域提供的就是这样一套算术，同时保留分配律等熟悉的运算规则。可以用一个字节表示元素的域 $GF(2^8)$ 包含 256 个元素，但它的运算并不是普通整数的模 256 运算。同样的字节组合，遵循的是另一套计算规则。

这就是后续学习需要准备的数学基础。RS 码用有限域上的多项式运算来处理符号；二元 BCH 码的符号虽然仍然是比特，但它的构造和译码也会用到更大的域。在研究这些编码之前，我们先把它们依赖的算术弄清楚：从定义域的基本规则出发，一步步走到 $GF(2^m)$ 中的实际运算。

## 域（Field）

<strong>域（Field）</strong>是一个集合 $F$，以及在该集合上定义的两种运算：加法运算 $a+b$ 和乘法运算 $a\cdot b$。其中，每个元素 $a$ 都存在加法逆元 $-a$，每个非零元素 $b$ 都存在乘法逆元 $b^{-1}$。由此便可以定义所谓的逆运算，即减法 $a-b$ 和除法 $a/b$。这些运算需要满足以下性质（域公理）：

+ **加法与乘法的结合律**：$a + (b + c) = (a + b) + c$，以及 $a \cdot (b \cdot c) = (a \cdot b) \cdot c$
+ **加法与乘法的交换律**：$a + b = b + a$，以及 $a \cdot b = b \cdot a$
+ **加法与乘法的单位元**：$F$ 中存在两个不同的元素 $\bold{0}$ 和 $\bold{1}$，使得 $a + \bold{0} = a$ 且 $a \cdot \bold{1} = a$
+ **加法逆元**：对于 $F$ 中的每个 $a$，都存在一个属于 $F$ 的元素，记为 $-a$，称为 $a$ 的加法逆元，使得 $a + (-a) = \bold{0}$。
+ **乘法逆元**：对于 $F$ 中的每个 $a\neq \bold{0}$，都存在一个属于 $F$ 的元素，记为 $a^{-1}$ 或 $1/a$，称为 $a$ 的乘法逆元，使得 $a \cdot a^{-1} = \bold{1}$
+ **乘法对加法的分配律**：$a \cdot (b + c) = (a \cdot b) + (a \cdot c)$

这些内容的核心是：

+ 定义了一个集合
+ 定义了四则运算（加法、减法、乘法和除法）
+ 运算具有封闭性，运算结果仍然属于该域

域是一种基本的代数结构，广泛应用于代数学、数论以及数学的许多其他领域。常见的域有：

+ 有理数 $\mathbb{Q}$
+ 实数 $\mathbb{R}$
+ 复数 $\mathbb{C}$

特别需要说明，整数集合 $\mathbb{Z}$ 不是域，因为它不具备乘法逆元。

严格来说，域总是与它的加法和乘法一同定义的，因此仅凭元素并不能完全确定一个域。即便如此，我们通常只凭元素来指称一个域，而将运算隐含在内。原因在于，我们并不依赖某一种具体的运算：只要在该集合上满足域公理，任何一组运算都能构成一个可用的域，而我们通常采用最常见、最著名的那一种。对有限域而言，这一点在后面会得到严格说明：元素个数相同的两个有限域总是同构的。

## 有限域（Finite Field），或称为伽罗瓦域（Galois Field）

有限域是只包含有限个元素的域。元素的个数也称为**域的阶**，有时也简称为域的**大小**，通常记为 $q$。

伽罗瓦证明，只有当阶是素数的幂时，有限域才存在，即 $q = p^m$，其中 $p$ 是素数，$m$ 是正整数（$m \geq 1$）。因此，有限域可以分为两类：**素域** $GF(p)$，以及 $m \ge 2$ 时的**扩域** $GF(p^m)$。

+ $p$ 是域的**特征**
+ $m$ 是域的**次数**
+ $q = p^m$ 是域的**阶**

![从素数土壤中生长出的数的茎秆示意图](/images/field-and-finite-field/number-stalks-prime-soil-diagram.png)

在继续之前，先简单说明一下<strong>符号（symbol）</strong>这个词。在编码中，数据被看作一个符号序列，而符号就是取自某个固定取值集合的一个值。比特是只有 0 和 1 两种取值的符号，字节则是有 256 种取值的符号。编码基于符号来计算校验，译码时也按符号纠正错误。有限域恰好提供了这样一个取值集合：域中的每个元素就是一个符号。$GF(2)$ 对应单比特符号，$GF(2^8)$ 对应字节符号。

### 素域

$GF(p)$ 称为**素域**，定义为“模 $p$ 的整数环”。也就是说，先进行通常的整数运算，再对 $p$ 取模。有限域的元素自然地表示为整数 ${0, 1, 2, ..., p-1}$。这就是前面提到的最常见的那种运算；用数学语言来说，它就是整数环 $\mathbb{Z}/p\mathbb{Z}$。

#### $GF(2)$

$GF(2)$ 是最小的有限域，因为根据定义，域中至少有两个不同的元素 $\bold{0}$ 和 $\bold{1}$。其中的加法可以简化为**异或（XOR）**，乘法则是**与（AND）**。

$GF(2)$ 的加法表与乘法表：

| $\oplus$ | $0$ | $1$ |
| --- | --- | --- |
| $0$ | $0$ | $1$ |
| $1$ | $1$ | $0$ |

| $\otimes$ | $0$ | $1$ |
| --- | --- | --- |
| $0$ | $0$ | $0$ |
| $1$ | $0$ | $1$ |

本文中，在不会与普通加法运算产生歧义时，GF 加法运算符记为 $+$；需要明确表示加法是在 GF 元素上进行时，则记为 $\oplus$。$\times$ 和 $\otimes$ 也采用同样的约定。

#### 素域的本原元素

有限域最重要的性质是它存在本原元素。有限域中存在本原元素 $\alpha$，使得域中所有非零元素都可以表示为 $\alpha^i$，其中 $i$ 是整数。由于元素的个数有限，因此 $\{0, 1, \alpha, \alpha^2, ..., \alpha^{q-2}\}$ 就是整个域。这意味着 $\alpha$ 是该域的一个**生成元**。

上述定理保证了至少存在一个本原元素，并且可能不止一个。例如，$3$ 和 $5$ 是 $GF(7)$ 的本原元素，但 $2$ 不是。

### 扩域

$GF(p)$ 的元素就是一些数字。含有 $p^m$ 个元素的域则不同，它记为 $GF(p^m)$，称为阶为 $p^m$ 的伽罗瓦域：按照定义，它的元素是 $GF(p)$ 上次数严格小于 $m$ 的多项式。形式上，它们都是如下多项式：

$$
\bm{a} = a_{m-1} x^{m-1} + a_{m-2} x^{m-2} + ... + a_1 x + a_0
$$

其中 $\bm{a} \in GF(p^m)$，且 $a_k \in GF(p)$。

$GF(p^m)$ 中恰好有 $p^m$ 个元素。

定义每个扩域时，都必须同时给出一个不可约多项式 $f(x)$。这个多项式决定了域中的算术运算，其中 $f(x)$ 是 $GF(p)$ 上次数为 $m$ 的**不可约多项式**。

$$
GF(p^m) = \frac{GF(p)[x]}{<f(x)>}
$$

在这一定义中，运算（**加法**和**乘法**）先按照通常的多项式运算进行，再对 $f(x)$ 取模。取模通过**多项式长除法**完成。

例如，取 $GF(2^3)$ 及 $f(x) = x^3 + x + 1$，用多项式长除法对 $x^5$ 取模。由于加法就是异或，减去一项与加上这一项的效果相同：

$$
\begin{aligned}
x^5 - x^2 \cdot f(x) &= x^5 + x^5 + x^3 + x^2 = x^3 + x^2 \\
(x^3 + x^2) - f(x) &= x^3 + x^2 + x^3 + x + 1 = x^2 + x + 1
\end{aligned}
$$

余式 $x^2 + x + 1$ 的次数小于 $m = 3$，除法结束：

$$
x^5 \equiv x^2 + x + 1 \pmod{f(x)}
$$

#### 本原多项式

如前面的定义所述，用于定义扩域 $GF(p^m)$ 的多项式必须是不可约的。在实践中，我们通常使用**本原多项式**来构造域。

本文接下来的部分不再讨论 $p \geq 3$ 的情况。

#### 扩域 $GF(2^m)$

$GF(2^m)$ 是 $GF(2)$ 的次数为 $m$ 的扩域。当素数 $p$ 为 2 时，通常习惯用二进制数表示 $GF(p^m)$ 中的元素，多项式中每一项的系数都对应元素二进制表示中的一个比特。数值两侧通常加上花括号（`{` 和 `}`），以表明这些数值表示的是域中的元素。

#### 扩域的本原元素

扩域中同样存在本原元素 $\alpha$，使得域中所有非零元素都可以表示为 $\alpha^i$，其中 $0 \le i \le q-2$ 为整数。对于 $GF(2^m)$，$\alpha = 2$ 通常是域中的一个本原元素，因为域通常由本原多项式构造。如果你在某篇文章中看到 $\alpha$ 却没有给出它的取值，就假定它是 $2$。

不过，情况并非总是如此。最著名的反例是 AES 所使用的域，即 $f(x) = x^8 + x^4 + x^3 + x + 1$ 上的 $GF(2^8)$。这个多项式不可约，但不是本原多项式：$2$ 的幂经过 $51$ 步就会循环，而不是 $255$ 步，因此 $2$ 只能生成 255 个非零元素中的 51 个。在这个域中，通常取 $3$ 作为本原元素。

#### 元素的表示

例如，不可约多项式为 $f(x) = x^3 + x + 1$ 的 $GF(2^3)$，其元素可以用不同的方式表示（另请注意 $\alpha^3 = \alpha + 1$，因此每个元素也可以写成 $\alpha^2$、$\alpha$ 和 $1$ 的组合）：

<div role="region" aria-label="GF(2^3) 中元素的表示方式" tabindex="0" style="overflow-x: auto;">

| $GF(2^3)$ 中的元素 | 二进制表示 | 十进制表示 | 指数表示* | 本原元素表示* |
| --- | --- | --- | --- | --- |
| $0$ | `{000}` | 0 | $0$ | $0$ |
| $1$ | `{001}` | 1 | $\alpha^0$ | $1$ |
| $x$ | `{010}` | 2 | $\alpha^1$ | $\alpha$ |
| $x+1$ | `{011}` | 3 | $\alpha^3$ | $\alpha + 1$ |
| $x^2$ | `{100}` | 4 | $\alpha^2$ | $\alpha^2$ |
| $x^2+1$ | `{101}` | 5 | $\alpha^6$ | $\alpha^2+1$ |
| $x^2+x$ | `{110}` | 6 | $\alpha^4$ | $\alpha^2 + \alpha$ |
| $x^2+x+1$ | `{111}` | 7 | $\alpha^5$ | $\alpha^2 + \alpha + 1$ |

</div>

*: $\alpha = 2$

#### 运算

按照定义，运算（**加法**和**乘法**）可以通过多项式除法完成。不过，还有更快捷的方法：$GF(2^m)$ 中的**加法**只需对两个元素的二进制表示做<strong>异或（XOR）</strong>，**乘法**则可以借助指数表示来计算：

$$
x \otimes y = \alpha^{log(x) + log(y)}
$$

其中，$log(\cdot)$ 是以本原元素 $\alpha$ 为底的对数运算。这使得我们可以用快速查找表来实现 GF 运算：

1. 构建 $log(x)$ 运算的查找表，根据元素的二进制表示得到指数值
2. 构建 $\alpha^{x}$ 运算的查找表，根据指数值得到元素的二进制表示
3. GF 中的乘法通过两次 $log(x)$ 查表和一次 $\alpha^x$ 查表完成

## 回顾

我们为单比特（$GF(2)$）和多比特（$GF(2^m)$）重新定义了加法与乘法运算。现在，我们已经具备了用于前向纠错（FEC）的基本代数结构。

## 相关概念

以下内容仅供参考。

### 同构

同构意味着，两个域的元素之间存在一一对应的映射，并且该映射保持域上的运算（加法和乘法）。

元素个数相同的两个有限域总是同构的，这意味着它们具有相同的代数结构，即使它们的元素可能不同。

从本质上说，当两个有限域的元素个数相同时，可以确定它们本质上是同一个域，只是表示方式可能不同。

### 多项式

$GF(p^m)$ 上的多项式 $f(x)$ 为：

$$
f(x) = a_k\cdot x^k + a_{k-1} \cdot x^{k-1} + ... + a_0
$$

其中：

+ $k$ 是次数
+ $x$ 是多项式中的不定元
+ $a_i, i = 0,1,...,k$ 是系数，且 $a_i \in GF(p^m)$

可以对多项式进行以下运算：

+ 加法与减法
+ 乘法与除法
+ 求值
+ 求满足 $f(x) = 0$ 的根
+ 在扩域中求根

### 不可约多项式

设 $F$ 是一个域。如果一个非常数多项式的系数属于 $F$，且无法分解为两个系数属于 $F$ 的非常数多项式的乘积，就称该多项式**在** $F$ **上不可约**。

要点是：

+ 不可约性取决于允许因式的系数取哪些值。这就是“在 $F$ 上不可约”的含义。

### 最小多项式

$GF(p^m)$ 中某个元素的最小多项式，是以该元素为 $GF(p^m)$ 中的根、具有二进制系数且次数最小的非零多项式。

```matlab
pol = gfminpol(k, m, p)
# or for p = 2
pr = minpol(m)
```

### 本原元素

元素 $\alpha$ 是 $GF(q)$ 的本原元素，当且仅当 $\{0, \alpha^0, \alpha^1, ..., \alpha^{q-2}\}$ 就是整个 $GF(q)$。换句话说：

+ $\alpha$ 是 $GF(q)$ 的一个生成元。
+ $\alpha$ 是 $GF(q)$ 中的一个本原 $(q-1)$ 次单位根。
+ $GF(q)$ 中的所有非零元素都可以写成 $\alpha^i$ 的形式，其中 $i$ 为某个自然数。

注意：如果选择本原多项式来构造扩域 $GF(2^m)$，那么 $2$（即元素 $x$）总是本原元素；如果构造所用的多项式只是不可约而非本原的，$2$ 就不一定是本原元素。

### 本原多项式

$GF(p^m)$ 上的本原多项式是 $GF(p^m)$ 中某个本原元素的最小多项式。换句话说，一个多项式满足以下条件时，就是本原多项式：

1. 它是次数为 $m$、系数属于 $GF(p)$ 的多项式 $f(x)$。
2. 它是首一多项式。
3. 它有一个根 $\alpha$，且 $\alpha$ 是本原元素。

另一种定义：

+ 设 $f(x)$ 是 $GF(p)$ 上次数为 $m$ 的不可约多项式，其中 $p$ 是素数。如果使 $f(x)$ 整除 $x^n-1$ 的最小正整数 $n$ 为 $n=p^m-1$，那么它就是本原多项式。

它具有以下性质：

+ 所有本原多项式都是不可约的，但不可约多项式不一定是本原多项式
+ 本原多项式的常数项必须非零。
+ 除 $GF(2)$ 上的 $x+1$ 以外，所有本原多项式的项数都是奇数。
+ 次数为 $m$ 的本原多项式在 $GF(p^m)$ 中有 $m$ 个不同的根，这些根都是本原元素

在实践中，可以使用 Python 代码查找本原多项式：

```python
import galois
for i in galois.primitive_polys(p, m):
    print(i)
```

也可以使用下面的 MATLAB 代码：

```matlab
pol = gfprimfd(m, "all", p)
# or for p = 2:
pr = primpoly(m, "all")
```
