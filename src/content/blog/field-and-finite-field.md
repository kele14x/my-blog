## 域

### 定义

> **域**是一个集合 $F$，以及在该集合上定义的两种运算：加法运算 $a+b$ 和乘法运算 $a\cdot b$。其中，每个元素 $a$ 都存在加法逆元 $-a$，每个非零元素 $b$ 都存在乘法逆元 $b^{-1}$。由此便可以定义所谓的逆运算，即减法 $a-b$ 和除法 $a/b$。这些运算需要满足以下性质（域公理）：
>
> + **加法与乘法的结合律**：$a + (b + c) = (a + b) + c$，以及 $a \cdot (b \cdot c) = (a \cdot b) \cdot c$
> + **加法与乘法的交换律**：$a + b = b + a$，以及 $a \cdot b = b \cdot a$
> + **加法与乘法的单位元**：$F$ 中存在两个不同的元素 $\bold{0}$ 和 $\bold{1}$，使得 $a + \bold{0} = a$ 且 $a \cdot \bold{1} = a$
> + **加法逆元**：对于 $F$ 中的每个 $a$，都存在一个属于 $F$ 的元素，记为 $-a$，称为 $a$ 的加法逆元，使得 $a + (-a) = \bold{0}$。
> + **乘法逆元**：对于 $F$ 中的每个 $a\neq \bold{0}$，都存在一个属于 $F$ 的元素，记为 $a^{-1}$ 或 $1/a$，称为 $a$ 的乘法逆元，使得 $a \cdot a^{-1} = \bold{1}$
> + **乘法对加法的分配律**：$a \cdot (b + c) = (a \cdot b) + (a \cdot c)$

要点：

+ 定义了一个集合
+ 定义了运算（加法、减法、乘法和除法）
+ 运算具有封闭性，运算结果仍然属于该域

因此，域是一种基本的代数结构，广泛应用于代数学、数论以及数学的许多其他领域。

### 示例

最常见的域有：

+ 有理数 $\mathbb{Q}$
+ 实数 $\mathbb{R}$
+ 复数 $\mathbb{C}$

特别地，整数集合 $\mathbb{Z}$ 不是域，因为它不具备乘法逆元。

## 有限域（伽罗瓦域）

### 定义

> 有限域是只包含有限个元素的域。元素的个数也称为**域的阶**。有限域的阶（也称为**大小**）通常记为 $q$。

伽罗瓦证明，只有当阶（即集合的大小）是素数的幂时，有限域才存在，即 $q = p^m$，其中 $p$ 是素数，$m$ 是正整数（$m \geq 1$）。因此，有限域可以分为两类：**素域** $GF(p)$，以及 $m \ge 2$ 时的**扩域** $GF(p^m)$。

+ $p$ 是域的**特征**
+ $m$ 是域的**次数**
+ $q = p^m$ 是域的**阶**

![从素数土壤中生长出的数的茎秆示意图](/images/field-and-finite-field/number-stalks-prime-soil-diagram.png)

### 素域

$GF(p)$ 称为**素域**，定义为“模 $p$ 的整数环”。也就是说，先进行通常的整数运算，再对 $p$ 取模。有限域的元素自然地表示为整数 ${0, 1, 2, ..., p-1}$。用数学语言来说，这就是整数环 $\mathbb{Z}/p\mathbb{Z}$。

#### 素域 $GF(2)$

$GF(2)$ 是最小的有限域，因为根据定义，域中至少有两个不同的元素 $\bold{0}$ 和 $\bold{1}$。其中的加法可以简化为**异或（XOR）**，乘法则是**与（AND）**。

![GF(2) 的加法表与乘法表](/images/field-and-finite-field/f2-addition-multiplication-tables.png)

本文中，在不会与普通加法运算产生歧义时，GF 加法运算符记为 $+$；需要明确表示加法是在 GF 元素上进行时，则记为 $\oplus$。$\times$ 和 $\otimes$ 也采用同样的约定。

```python
import galois
GF = galois.GF(2)
zero = GF(0)
one = GF(1)
zero + one
# GF(1, order=2)
zero * one
# GF(0, order=2)
```

#### 本原元素

> $GF(p)$ 中存在本原元素 $\alpha$，使得域中所有非零元素都可以表示为 $\alpha^i$。由于元素的个数有限，因此 $\{0, 1, \alpha, \alpha^2, ..., \alpha^{p-2}\}$ 就是整个域。

可以用 Python 查找素域中的本原元素：

```python
import galois
p = 7
for i in galois.primitive_roots(p):
    print(i)
# 3
# 5
```

### 扩域

> 含有 $p^m$ 个元素的域记为 $GF(p^m)$，称为阶为 $p^m$ 的伽罗瓦域。$GF(p^m)$ 的元素是 $GF(p)$ 上次数严格小于 $m$ 的多项式。形式上，它们都是如下多项式：
>
> $$
> \bm{a} = a_{m-1} x^{m-1} + a_{m-2} x^{m-2} + ... + a_1 x + a_0
> $$
>
> 其中 $\bm{a} \in GF(p^m)$，且 $a_k \in GF(p)$。

$GF(p^m)$ 中恰好有 $p^m$ 个元素。

定义每个扩域时，都必须同时给出一个不可约多项式 $f(x)$。这个多项式决定了域中的算术运算，其中 $f(x)$ 是 $GF(p)$ 上次数为 $m$ 的**不可约多项式**。

$$
GF(p^m) = \frac{GF(p)[x]}{<f(x)>}
$$

在这一定义中，运算（**加法**和**乘法**）先按照通常的多项式运算进行，再对 $f(x)$ 取模。取模通过**多项式长除法**完成。

```python
import galois
p = 2
m = 8
GF256 = galois.GF(p, m)
print(GF256.properties)
# Galois Field:
#  name: GF(2^8)
#  characteristic: 2
#  degree: 8
#  order: 256
#  irreducible_poly: x^8 + x^4 + x^3 + x^2 + 1
#  is_primitive_poly: True
#  primitive_element: x
```

#### 本原元素

域中存在本原元素 $\alpha$，使得所有非零元素都可以表示为 $\alpha^i$，其中 $i$ 是整数。这意味着 $\alpha$ 是该域的一个**生成元**。

```python
import galois
p = 2
m = 8
poly = 'x^8 + x^4 + x^3 + x^2 + 1'
gf = galois.GF(p, m, irreducible_poly=poly)
gf.primitive_elements
```

通常，$\alpha = 2$ 是域中的一个本原元素。因此，域中的每个元素也可以用 $\alpha$ 的指数来表示。上表展示了 $GF(2^3)$ 的例子。

还要注意，$\alpha^2 = \alpha + 1$，因此域中的元素也可以表示为 $\alpha^2$、$\alpha$ 和 $1$ 的组合。

#### 本原多项式

如前面的定义所述，用于定义扩域 $GF(p^m)$ 的多项式必须是不可约的。在实践中，我们通常使用**本原多项式**来构造域。

本文接下来的部分不再讨论 $p \geq 3$ 的情况。

#### 扩域 $GF(2^m)$

$GF(2^m)$ 是 $GF(2)$ 的次数为 $m$ 的扩域。当素数 $p$ 为 2 时，通常习惯用二进制数表示 $GF(p^n)$ 中的元素，多项式中每一项的系数都对应元素二进制表示中的一个比特。数值两侧通常加上花括号（`{` 和 `}`），以表明这些数值表示的是域中的元素。

例如，对于不可约多项式为 $f(x) = x^3 + x + 1$ 的 $GF(2^3)$，其元素可以用不同的方式表示：

<div role="region" aria-label="GF(2^3) 中元素的表示方式" tabindex="0" style="overflow-x: auto;">

| $GF(2^3)$ 中的元素 | 二进制表示 | 十进制表示 | 指数表示* | 本原元素表示* |
| --- | --- | --- | --- | --- |
| $0$ | `{000}` | 0 | $0$ | $0$ |
| $1$ | `{001}` | 1 | $\alpha^0$ | $1$ |
| $x$ | `{010}` | 2 | $\alpha^1$ | $\alpha$ |
| $x+1$ | `{011}` | 3 | $\alpha^3$ | $\alpha + 1$ |
| $x^2$ | `{100}` | 4 | $\alpha^2$ | $\alpha^2$ |
| $x^2+1$ | `{101}` | 5 | $\alpha^6$ | $\alpha^2+1$ |
| $x^2+x$ | `{110}` | 6 | $\alpha^4$ | $\alpha^2 + \alpha$ |
| $x^2+x+1$ | `{111}` | 7 | $\alpha^5$ | $\alpha^2 + \alpha + 1$ |

</div>

*: $\alpha = 2$

$GF(2^m)$ 中的**加法**只需对两个元素的二进制表示做**异或（XOR）**即可。**乘法**可以按照定义（多项式除法）进行，也可以使用指数表示来计算：

$$
x \otimes y = \alpha^{log(x) + log(y)}
$$

其中，$log(\cdot)$ 是以本原元素 $\alpha$ 为底的对数运算。这使得我们可以用快速查找表来实现 GF 运算：

1. 构建 $log(x)$ 运算的查找表，根据元素的二进制表示得到指数值
2. 构建 $\alpha^{x}$ 运算的查找表，根据指数值得到元素的二进制表示
3. GF 中的乘法通过两次 $log(x)$ 查表和一次 $\alpha^x$ 查表完成

## 回顾

我们为单比特（$GF(2)$）和多比特（$GF(2^m)$）重新定义了加法与乘法运算。现在，我们已经具备了用于前向纠错（FEC）的基本代数结构。

## 相关概念

以下内容仅供参考。

### 同构

同构意味着，两个域的元素之间存在一一对应的映射，并且该映射保持域上的运算（加法和乘法）。

元素个数相同的两个有限域总是同构的，这意味着它们具有相同的代数结构，即使它们的元素可能不同。

从本质上说，当两个有限域的元素个数相同时，可以确定它们本质上是同一个域，只是表示方式可能不同。

### 多项式

$GF(p^m)$ 上的多项式 $f(x)$ 为：

$$
f(x) = a_k\cdot x^k + a_{k-1} \cdot x^{k-1} + ... + a_0
$$

其中：

+ $k$ 是阶数
+ $x$ 是多项式中的不定元
+ $a_i, i = 0,1,...,k$ 是系数，且 $a_i \in GF(p^m)$

可以对多项式进行以下运算：

+ 加法与减法
+ 乘法与除法
+ 求值
+ 求满足 $f(x) = 0$ 的根
+ 在扩域中求根

### 不可约多项式

设 $F$ 是一个域。如果一个非常数多项式的系数属于 $F$，且无法分解为两个系数属于 $F$ 的非常数多项式的乘积，就称该多项式**在** $F$ **上不可约**。

要点是：

+ 不可约性取决于允许因式的系数取哪些值。这就是“在 $F$ 上不可约”的含义。

### 最小多项式

$GF(p^m)$ 中某个元素的最小多项式，是以该元素为 $GF(p^m)$ 中的根、具有二进制系数且次数最小的非零多项式。

```matlab
pol = gfminpol(k, m, p)
# or for p = 1
pr = minpol(m)
```

### 本原元素

元素 $\alpha$ 是 $GF(q)$ 的本原元素，当且仅当 $\{0, \alpha^0, \alpha^1, ..., \alpha^{q-1}\}$ 就是整个 $GF(q)$。换句话说：

+ $\alpha$ 是 $GF(q)$ 的一个生成元。
+ $\alpha$ 是 $GF(q)$ 中的一个本原 $(q-1)$ 次单位根。
+ $GF(q)$ 中的所有非零元素都可以写成 $\alpha^i$ 的形式，其中 $i$ 为某个自然数。

例如，$2$ 是域 $GF(3)$ 和 $GF(5)$ 的本原元素，但不是 $GF(7)$ 的本原元素。

### 本原多项式

$GF(p^m)$ 上的本原多项式是 $GF(p^m)$ 中某个本原元素的最小多项式。换句话说，一个多项式满足以下条件时，就是本原多项式：

1. 它是次数为 $m$、系数属于 $GF(p)$ 的多项式 $f(x)$。
2. 它是首一多项式。
3. 它有一个根 $\alpha$，且 $\alpha$ 是本原元素。

另一种定义：

+ 设 $f(x)$ 是 $GF(p)$ 上次数为 m 的不可约多项式，其中 p 是素数。如果使 $f(x)$ 整除 $x^n-1$ 的最小正整数 $n$ 为 $n=p^m-1$，那么它就是本原多项式。

它具有以下性质：

+ 所有本原多项式都是不可约的，但不可约多项式不一定是本原多项式
+ 本原多项式的常数项必须非零。
+ 除 $GF(2)$ 上的 $x+1$ 以外，所有本原多项式的项数都是奇数。
+ 次数为 $m$ 的本原多项式在 $GF(p^m)$ 中有 $m$ 个不同的根，这些根都是本原元素

在实践中，可以使用 Python 代码查找本原多项式：

```python
import galois
for i in galois.primitive_polys(p, m):
    print(i)
```

也可以使用下面的 MATLAB 代码：

```matlab
pol = gfprimfd(m, "all", p)
# or for p = 2:
pr = primpoly(m, "all")
```

+ 斐波那契 LFSR（多对一）
+ 伽罗瓦 LFSR（一对多）
+ m 序列
+ M 序列（两个 m 序列异或）
